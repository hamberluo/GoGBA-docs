2. Description of Service

GoGBA is a Game Boy Advance (GBA) game emulator application that allows you to play GBA games on your mobile device. The App provides emulation functionality using the libretro mGBA core. Additional features include an optional Premium upgrade (in-app purchase on iOS/Android) that unlocks Cloud Save, enabling you to sync game save files across devices via Google Drive or iCloud. A separate optional AI Screen Translation subscription (in-app purchase) may be available; when purchased and activated, it sends captured game screen images to Google's AI services to generate translations. How that data is handled is described in our Privacy Policy.
