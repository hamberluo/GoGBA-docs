Frequently Asked Questions

How do I add games to GoGBA?

GoGBA supports multiple ways to add games:

  1. Individual file selection: Tap the "Add Games" button and select a single .gba file using the file picker. The file will be automatically copied to the app's games directory.
  2. Auto-scan directory: The app automatically scans the games directory on startup and when loading the home page. Simply place .gba files in the app's games directory.
  3. External app opening: Open .gba files from other apps (file managers, email, etc.). GoGBA will automatically import and open the game.
  4. ZIP support: ZIP compressed files are automatically extracted when added.

Games are stored in the app's documents directory under the games subdirectory.

Where are my save files stored?

Save files (.sav files) are stored locally on your device:

  • Android: External storage directory
  • iOS: App Documents directory

Save files are automatically saved every 10 seconds, when you exit the game, or when the app goes to the background.

Can I use GoGBA with a controller?

Yes! GoGBA has full gamepad support on both Android and iOS:

  • Automatically detects connected gamepads
  • Customizable button mapping (configure in Settings → Controls → Gamepad Mapping)
  • Option to hide virtual buttons when gamepad is connected
  • Works with most standard Bluetooth and USB controllers

To configure gamepad buttons, go to Settings → Controls → Gamepad Mapping.

Does GoGBA support cloud saves?

Cloud save functionality is not currently available. All saves are stored locally on your device. We recommend regularly backing up your save files.

How do I change the game speed?

While playing a game, tap the speed button (1x, 2x, or 3x) located in the game interface. You can adjust the speed from 1x (normal) to 3x (fastest).

Can I customize the virtual button layout?

GoGBA uses fixed button layouts for consistency, but you can customize:

  • Button opacity: Adjust transparency from 10% to 100% (Settings → Controls → Button Opacity)
  • Control mode: Switch between Normal (standard GBA layout) and Arcade (LRAB four-directional buttons) modes
  • Haptic feedback: Enable/disable and adjust vibration strength (light/medium/heavy)

Button position and size editing are not available by design to maintain consistency and avoid configuration complexity.

My game crashes or doesn't load. What should I do?

If you encounter crashes or loading issues:

  1. Ensure your ROM file is a valid GBA file (.gba extension)
  2. Try restarting the App
  3. Check that you have sufficient storage space
  4. Update to the latest version of GoGBA
  5. Contact support with details about the issue

Can I play games in both portrait and landscape mode?

Yes! GoGBA supports both portrait and landscape orientations. You can lock the orientation in Settings → Display → Orientation, or toggle it while playing a game through the in-game menu.

How do I clear the cover cache?

To clear cached game covers, go to Settings → Data → Clear Cover Cache. This will remove all downloaded cover images, and they will be re-downloaded when needed.

What is RetroAchievements?

RetroAchievements is an achievement system for retro games. GoGBA integrates with RetroAchievements to provide:

  • Achievement unlocking and tracking
  • Leaderboards for competitive play
  • Rich Presence (shows your game status to others)
  • Hardcore mode (no save states, no rewinding)
  • Encore mode (replay achievements)

To use RetroAchievements, go to Settings → Achievements → RetroAchievements and log in with your RetroAchievements account. You can create a free account at retroachievements.org.

How do I favorite a game?

Long-press on any game in your library to open the context menu, then select "Favorite" or "Unfavorite". Favorite games are displayed at the top of your library, before recent games.

Can I import a BIOS file?

Yes! Importing a BIOS file can improve game compatibility. To import a BIOS:

  1. Go to Settings → Data → BIOS Management
  2. Tap "Import BIOS"
  3. Select your BIOS file (bios.bin)
  4. The BIOS will be stored in the app's support directory

Note: You must legally own the BIOS file. GoGBA does not provide BIOS files.

What video filters are available?

GoGBA supports multiple video rendering filters for authentic retro visuals:

  • LCD: Simulates LCD screen effect
  • Scanlines: Adds scanline effect for CRT-like appearance
  • Bilinear: Smooth scaling filter
  • HQ2x: High-quality 2x scaling filter

You can enable multiple filters simultaneously. Configure in Settings → Controls → Video Render Filters.
